The Corus test suite is a conformance and agency suite.

Conformance tests prove that the engine preserves the Corus layer model:
`.timpo` anchors observation, `.domain` defines meaning, `.surface` connects meaning, `.lens` shapes traversal, `.profile` initiates agency, `.value` explains customer significance, and `.context` is reconstructed.

Agentic tests prove that an agent can move through this reconstructed context safely:
it may traverse, prioritize, propose, explain, and initiate permitted actions; it may not invent nodes, edges, values, permissions, or unsupported because traces.

A passing suite proves the Codex-generated implementation is not merely functional code. It proves that the implementation behaves like a Corus engine.

Playground commands are documented in [docs/playground.md](../docs/playground.md).

Short form:

```txt
The engine may derive context.
The agent may move through context.
It may not invent it.
```
